abri com o vs code e executar na ordem

1. criar o arquivo .env a partir do exemplo
cp .env.example .env

2. construir e iniciar os containers
docker compose build
docker compose up -d

se tudo der certo abra http://localhost:8080/
(deve aparecer a mensagem de conexão com o MySQL)


/**
 * Cria (ou redefine a senha de) um usuário do painel.
 *
 * Rode de dentro do projeto:
 *   docker compose exec php php /var/www/src/bin/criar-usuario.php
 *
 * Ou informando os dados:
 *   docker compose exec php php /var/www/src/bin/criar-usuario.php "Maria" maria "SenhaForte@2026"
 *
 * Sem argumentos, usa os valores padrão de apresentação.
 */


para acessar o MySQL por fora (ex.: HeidiSQL, DBeaver, mysql client) = host localhost, porta 3307

para ver os logs = docker compose logs -f

para parar o docker = docker compose down

3. aplicar as migrations (obrigatorio se o banco ja existe)

o init.sql so roda na primeira subida, com o volume vazio. se o banco ja
existia, o schema fica antigo e da erro (ex.: "Data truncated for column
'status'" ao usar o status andamento).

docker compose exec -T db sh -c 'exec mysql -uroot -p"$MYSQL_ROOT_PASSWORD" "$MYSQL_DATABASE"' \
  < docker/php/db/migrations/001_status_andamento.sql

docker compose exec -T db sh -c 'exec mysql -uroot -p"$MYSQL_ROOT_PASSWORD" "$MYSQL_DATABASE"' \
  < docker/php/db/migrations/002_historico_fk_cascade.sql

conferir se pegou (tem que aparecer andamento no enum e CASCADE na fk):

docker compose exec -T db sh -c 'exec mysql -uroot -p"$MYSQL_ROOT_PASSWORD" "$MYSQL_DATABASE" -e "
  SELECT COLUMN_NAME, COLUMN_TYPE FROM information_schema.COLUMNS
    WHERE TABLE_SCHEMA = DATABASE() AND COLUMN_NAME = \"status\";
  SELECT CONSTRAINT_NAME, DELETE_RULE FROM information_schema.REFERENTIAL_CONSTRAINTS
    WHERE CONSTRAINT_SCHEMA = DATABASE();"'

nunca use "docker compose down -v" para consertar schema: o -v apaga o volume
com os dados. aplique as migrations.
